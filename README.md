# Calculadora de Álgebra Lineal

Programa en C++ que calcula el determinante y la matriz inversa de una matriz 3x3.

## Características

- Ingreso de una matriz 3x3 por consola
- Cálculo del determinante
- Cálculo de la matriz inversa (si el determinante es distinto de 0)
- Menú interactivo

## Cómo compilar y ejecutar

Necesitas tener instalado un compilador de C++ (g++).

Linux / macOS:

    g++ Calculadora_Algebra_Lineal.cpp -o calculadora
    ./calculadora

Windows:

    g++ Calculadora_Algebra_Lineal.cpp -o calculadora.exe
    calculadora.exe

## Ejemplo de uso

1. Elige la opción 1 en el menú.
2. Ingresa los 9 elementos de la matriz.
3. El programa muestra la matriz, su determinante y su inversa.
